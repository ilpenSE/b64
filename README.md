# Base64 Encoder and Decoder in C

- Quick, simple base64 encoder and decoder functions in C.
- Using [str.h](https://github.com/ilpenSE/str.h.git) and [bw.h](https://github.com/ilpenSE/bw.h.git).
- `b64_encode` and `b64_decode` functions are in `b64.c` go get implementations from there.

## Quick Start

- Build and run:
```bash
make && ./main
```

- It should show this:
```
encoded = 'YWJjZGVmZQ'
decoded = 'abcdefe'
```
